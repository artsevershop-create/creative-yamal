# Креативный Ямал — прототип

Отдельное приложение Next.js для прототипа платформы по ТЗ. Исходный проект в родительской папке не заменяется.

## Запуск

```powershell
cd creative-yamal
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Проверка и production-сборка

```powershell
pnpm exec tsc --noEmit
pnpm build
pnpm start
```

## Статус

Это визуальный прототип платформы креативных индустрий Ямала. Атлас использует географический контур и координаты населённых пунктов; источники указаны на сайте. Профили участников и условия отбора находятся на этапе концепции.

## Отправка заявок

Форма отправляет заявки через FormSubmit на artsevershop@gmail.com. После отправки и проверки от спама посетитель возвращается на страницу `/thanks/`. Поле email используется для ответа заявителю. Ключи доступа не требуются. Кнопка сохранения черновика сохраняет данные только в текущем браузере и не отправляет письмо.

Для запуска доставки необходимо один раз активировать адрес получателя: отправить первое реальное обращение через форму, открыть письмо FormSubmit в artsevershop@gmail.com (при необходимости проверить спам) и подтвердить адрес. До подтверждения доставка не активна. После активации отправьте обращение повторно, если оно не поступило. Доставка письма при разработке не проверялась.

## Публикация

Сайт: https://artsevershop-create.github.io/creative-yamal/

Изменения в ветке `main` автоматически собираются и публикуются через GitHub Actions / GitHub Pages. Для статического экспорта используется переменная `GITHUB_PAGES=true`, затем `node scripts/prepare-pages.cjs` подготавливает пути изображений для размещения в подпапке.
