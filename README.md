# Креативный Ямал — прототип

Отдельное приложение Next.js для прототипа платформы по ТЗ. Исходный проект в родительской папке не заменяется.

## Запуск

```powershell
cd creative-yamal
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Проверка и production-сборка

```powershell
pnpm exec tsc --noEmit
pnpm build
pnpm start
```

## Статус

Это визуальный прототип платформы креативных индустрий Ямала. Атлас использует географический контур и координаты населённых пунктов; источники указаны на сайте. Профили участников и условия отбора находятся на этапе концепции. Форма сохраняет черновик в браузере, отправка заявок пока не подключена.

## Публикация

Сайт: https://artsevershop-create.github.io/creative-yamal/

Изменения в ветке `main` автоматически собираются и публикуются через GitHub Actions / GitHub Pages. Для статического экспорта используется переменная `GITHUB_PAGES=true`, затем `node scripts/prepare-pages.cjs` подготавливает пути изображений для размещения в подпапке.
